# 🌧 Ghana Rainfall Forecast Challenge

##  Overview
This is a Python-based educational game that uses real rainfall data from Ghana to simulate weather forecasting. The player predicts whether rainfall will be Low, Medium, or High based on previous trends.

## How the Game Works
- The game runs for 10 rounds  
- Each round shows previous rainfall data  
- Player predicts next rainfall category (Low / Medium / High)  
- Final score and performance level are displayed  

## Scoring System
- Each correct prediction = +1 point  
- Final score is shown out of 10  
- Accuracy percentage is calculated  

### Performance Levels:
- 90%+ → Weather Master  
- 70–89% → Chief Meteorologist  
- 50–69% → Weather Analyst  
- Below 50% → Junior Forecaster  

##  Dataset Requirements
File name:
ghana-precipitation-2000-2015.csv

Required columns:
- Precipitation (mm)
- Year
- Month
